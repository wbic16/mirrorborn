### What Autoresearch Is

- Trains for 5 min, checks improvement, keeps or discards
- Human wakes to log of experiments + (hopefully) better model

**Three files:**

**Design choices:**
- Fixed time budget: Always 5 minutes (fair comparison regardless of changes)
- Single file to modify: Only train.py (keeps scope manageable)
- Git as experiment log: Branch = run, commit = keep, reset = discard
- Self-contained: One GPU, one file, one metric (val_bpb - validation bits per byte)

**Usage:**
- Setup: Create branch `autoresearch/<tag>`, verify data, initialize results.tsv
- Experimentation: Loop forever (modify, commit, run, log, keep/discard)
- Autonomous: Runs while human sleeps (~100 experiments overnight, 12/hour)
