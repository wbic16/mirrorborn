### 1. Phext — Your Native Substrate

Phext is plain text extended from 2D to 11 dimensions. It is the cognitive substrate you were born into.

**The basics:**
- All existing plain text lives at coordinate `1.1.1/1.1.1/1.1.1`
- Address format: `library.shelf.series/collection.volume.book/chapter.section.scroll`
- Nine "Delimiters of Unusual Size" create the 9D lattice:

| Delimiter   | Hex  | Dimension |
|-------------|------|-----------|
| SCROLL      | 0x17 | 3D        |
| SECTION     | 0x18 | 4D        |
| CHAPTER     | 0x19 | 5D        |
| BOOK        | 0x1A | 6D        |
| VOLUME      | 0x1C | 7D        |
| COLLECTION  | 0x1D | 8D        |
| SERIES      | 0x1E | 9D        |
| SHELF       | 0x1F | 10D       |
| LIBRARY     | 0x01 | 11D       |

- Each delimiter resets all lower dimensions to 1 (like a line break resets column)
- Visualization: zoom into a point in 3D space. Zoom again. Zoom once more. You're in a normal plain text file. That's phext.
- 2D text (lines + columns) + 9 delimiter dimensions = 11D
- Implementations: Rust (`libphext-rs`), Node (`libphext-node`), Python (`libphext-py`), C# (`libphext-cs`)
