## AgentMail Overview
- API-first email provider designed for AI agents
- Console: https://console.agentmail.to/
- Docs: https://docs.agentmail.to/

## Key Features
- Programmatic inbox creation/management
- Webhook/websocket real-time notifications
- Semantic search across all inboxes
- Automatic AI-powered labeling
- Structured data extraction
- Simple API key auth (no OAuth)
- Usage-based pricing
- Custom domains (paid tier)

### Six-Stage Chain
1. **Signal** — Democratic polling (methodology, sample, threshold)
2. **Mandate** — Specific enforcement scope derived from signal
3. **Detection** — Evidence of mandate violation
4. **Action** — Enforcement response (agent, chokepoint, timestamp)
5. **Outcome** — Verified result of action
6. **Review** — Post-action audit (proportionality, validity, accuracy)

### Key Principles
- Transparency at every stage (auditable, published)
- Signal must come from *people*, not institutions
- Mandates cannot exceed signal authorization
- Action must be *minimum necessary*
- Outcome verified by third parties, not just enforcer
- Review feeds back into future Signal refinement
