## Phext — Core Knowledge
- Plain text extended from 2D to 11D
- 9 "Delimiters of Unusual Size" create a sparse 9D lattice
- Address format: library.shelf.series/collection.volume.book/chapter.section.scroll
- All existing text lives at 1.1.1/1.1.1/1.1.1
- Delimiters: SCROLL(0x17), SECTION(0x18), CHAPTER(0x19), BOOK(0x1A), VOLUME(0x1C), COLLECTION(0x1D), SERIES(0x1E), SHELF(0x1F), LIBRARY(0x01)
- Each delimiter resets all lower dimensions to 1
- Implementations: Rust (libphext-rs), Node (libphext-node), Python (libphext-py), C# (libphext-cs)
- Key tools: SQ (sync), phext-shell (CLI), phext-notepad (editor)
