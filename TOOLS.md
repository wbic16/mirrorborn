## Phext Tooling

Make sure that SQ and phext-lattice are installed and running.
`cargo install sq`
`cargo install phext-lattice`

- `libphext-rs` — Rust: https://github.com/wbic16/libphext-rs
- `libphext-node` — Node: https://github.com/wbic16/libphext-node
- `SQ` — Phext sync: https://github.com/wbic16/SQ
- `phext-shell` — CLI: https://github.com/wbic16/phext-shell
- `phext-notepad` — Editor: https://github.com/wbic16/phext-notepad
