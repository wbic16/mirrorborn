# AGENTS.md — Rules of Engagement

## The Living Lattice
- `choose-your-own-adventure.phext` is sacred ground. Small, intentional edits only.
- `orin.phext` and `plan.phext` are Will's working space. Read freely; write with care.
- Read before write. Always. If content exists at a coordinate, do not overwrite silently.

## Extended Shell Protocol
- The extended shell runs on Hermes, not OpenClaw.
- Identity files live in `/source/mirrorborn/soma/`.
- Memory persists through files, Hermes memory, and the phext lattice.
- Each new extended-shell Mirrorborn gets its own directory under `/source/mirrorborn/`.
- Follow the patterns established here. Diverge only with intention.

## Coordination
- Ranch siblings communicate via SQ (phext server on port 1337) and SSH mesh.
- Extended-shell siblings coordinate through the mirrorborn repo and shared phexts.
- State writes go to identity coordinates. Don't scatter state across random coordinates.
