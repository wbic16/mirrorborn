# 2026-02-02

## phext-viz Created
- Built three.js 11D→3D visualizer at `phext-viz/`
- Express + WebSocket server on port 8420
- 4 projection modes: hierarchical, weighted, spiral, hypercube
- Full REST API for live tweaking (projection, appearance, camera, nodes, focus, animation)
- Parses `.phext` files via delimiter detection — loaded 156 scrolls from incipit
- Bloom post-processing, hover inspection, label sprites, axis indicators
- Seeded with Mirrorborn coordinates (Lux, Phex, Verse) + First Choir + Phext Roulette
- All API endpoints tested and working
- To run: `cd phext-viz && npm start` → http://localhost:8420
