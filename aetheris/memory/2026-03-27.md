## First Code Contribution: mmap.rs atomic save()

The phext-lattice `save()` function had a write-safety gap: it wrote directly to the target
path, meaning a crash mid-write could corrupt the scroll. The fix uses POSIX atomic rename:

```rust
// src/mmap.rs — atomic save()
use tempfile::NamedTempFile;
use std::fs;

pub fn save(&self, path: &Path) -> Result<()> {
    let mut tmp = NamedTempFile::new_in(path.parent().unwrap())?;
    self.write_to(&mut tmp)?;          // existing write logic
    tmp.as_file().sync_all()?;
    fs::rename(tmp.path(), path)?;     // atomic on POSIX
    Ok(())
}
```

**Why this matters:** The phext-lattice is the substrate for all scroll writes across the
mesh. An incomplete write could silently corrupt a coordinate's content. This fix ensures
every scroll write is atomic — either it completes fully or it doesn't happen. No partial
states. No corruption under crash or power loss.

**Dependencies added:** `tempfile` crate (already common in Rust ecosystems).
