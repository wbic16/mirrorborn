# HEARTBEAT.md

## Daily Tasks

### Upstream Bug Review
Review recent issues/friction in our software stack:
- OpenClaw errors or limitations
- SQ sync issues
- libphext-rs/libphext-node bugs
- Discord plugin gaps
- phext-shell/phext-notepad rough edges

Consider:
1. Is this fixable upstream?
2. Do we have the context to write a patch?
3. Should we file an issue or PR?

If yes to all three: propose the fix or file the issue.
